# CPA注册会计师学习资料库

本目录包含CPA注册会计师考试的学习资料，按科目分类整理。

## 目录结构

```
cpa-resources/
├── 会计/                    # 会计科目学习资料
├── 审计/                    # 审计科目学习资料
├── 税法/                    # 税法科目学习资料
├── 经济法/                  # 经济法科目学习资料
├── 财务成本管理/            # 财管科目学习资料
├── 公司战略与风险管理/      # 战略科目学习资料
└── README.md               # 本说明文件
```

## 科目说明

### 会计
- 考试时间：2小时
- 满分：100分
- 及格线：60分
- 重点章节：长期股权投资、企业合并、合并财务报表、金融工具、收入、所得税

### 审计
- 考试时间：2小时
- 满分：100分
- 及格线：60分
- 重点章节：审计计划、风险评估、销售与收款循环、生产与存货循环、审计报告

### 税法
- 考试时间：2小时
- 满分：100分
- 及格线：60分
- 重点章节：增值税、消费税、企业所得税、个人所得税、国际税收

### 经济法
- 考试时间：2小时
- 满分：100分
- 及格线：60分
- 重点章节：物权法、合同法、公司法、证券法、企业破产法

### 财务成本管理
- 考试时间：2.5小时
- 满分：100分
- 及格线：60分
- 重点章节：财务报表分析、企业价值评估、资本成本、资本结构、期权价值评估

### 公司战略与风险管理
- 考试时间：2小时
- 满分：100分
- 及格线：60分
- 重点章节：战略分析、战略选择、战略实施、风险与风险管理

## 使用说明

1. 每个科目目录下包含该科目的学习资料
2. 资料格式为Markdown，便于阅读和编辑
3. 可配合CPA备考系统使用，记录学习进度和笔记

## 资料来源

- 官方考试大纲
- 历年真题解析
- 高质量学习笔记
- 专业教材重点章节总结
