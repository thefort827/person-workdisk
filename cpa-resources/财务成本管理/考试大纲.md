# CPA财务成本管理科目考试大纲

## 考试基本信息

- **考试时间**：2.5小时
- **满分**：100分
- **及格线**：60分
- **考试形式**：客观题（单选、多选）+ 计算分析题 + 综合题

## 重点章节

### 必考章节
1. **财务报表分析**：财务比率分析、管理用财务报表
2. **资本成本**：加权平均资本成本的计算
3. **投资项目资本预算**：净现值、内含报酬率的计算
4. **资本结构**：杠杆系数的计算
5. **本量利分析**：盈亏临界点的计算

### 高频考点
- 财务比率的计算与分析
- 净现值和内含报酬率的计算
- 加权平均资本成本的计算
- 杠杆系数的计算
- 盈亏临界点和安全边际的计算

## 学习建议

1. **理解公式原理**：财务成本管理涉及大量公式，需要理解其推导过程
2. **多做计算题**：考试计算量大，需要大量练习
3. **关注公式之间的联系**：很多公式之间存在逻辑关系
4. **使用计算器**：考试允许使用计算器，熟练使用
